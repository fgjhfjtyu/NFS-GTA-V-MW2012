# NFS MW 2012 – GTA V Vehicle Conversion Workbench

برنامه ویندوزی برای آماده‌سازی گردش‌کار تبدیل مدل خودروهای GTA V به خودروهای قابل نصب در **Need for Speed: Most Wanted (2012)**، همراه با نصب امن BNDL، نسخه پشتیبان و بازگردانی.

> **محدودیت مهم و شفاف:** این پروژه یک «تبدیل‌کننده جادویی یک‌کلیکی» نیست. فایل‌های باینری GTA V (مثل YFT/YTD) و بسته‌های خودرو NFS دو ساختار متفاوت دارند. برنامه آماده‌سازی مود، اسکن فایل‌ها، راهنمای مراحل، بررسی ابزارها، اعتبارسنجی بسته OBJ/MTL/DDS و نصب/بازگردانی BNDL را مدیریت می‌کند. تبدیل هندسه و تنظیم اجزای خودرو هنوز باید با ابزارهای اختصاصی و در Blender آماده شود.

## امکانات این نسخه

- رابط گرافیکی فارسی با سه بخش: تبدیل خودرو، مدیریت مودهای NFS و ابزارهای موردنیاز.
- دریافت پوشه مود یا آرشیو ZIP/RAR/7Z و فایل RPF (RPF در این برنامه باز نمی‌شود؛ فقط به فضای کاری کپی می‌شود).
- استخراج ZIP با محافظت در برابر Zip Slip، لینک نمادین و آرشیوهای حجیم؛ برای RAR/7Z به 7-Zip نیاز است.
- ساخت فضای کاری مرحله‌بندی‌شده و کپی امن خودروی مرجع از `VEHICLES`.
- شناسایی خودکار CodeWalker، Noesis، 7-Zip، Blender و NVIDIA Texture Tools در مسیرهای رایج؛ امکان معرفی مسیر دستی.
- اعتبارسنجی OBJ/MTL/DDS: وجود رأس و Face، ارجاع MTL، تعداد Material برای هر Mesh، وجود تکسچرها، هدر DDS و سقف ۶۰٬۰۰۰ رأس در مسیر قدیمی NFSMW12VMT.
- نصب اتمی BNDL خودرو و ذخیره بکاپ اصلی در `_ModManager/backups`.
- بازگردانی بکاپ از فهرست مودهای نصب‌شده. از نصب تو در تو روی یک فایل که قبلاً تحت مدیریت مود دیگری است جلوگیری می‌شود.
- نصب مودهای عادی NFS از پوشه یا ZIP؛ فایل‌های خام GTA V در مسیر نصب عادی رد می‌شوند.
- تست‌های خودکار برای نصب، بازگردانی، مسیر ناامن آرشیو، فایل‌های خام GTA و اعتبارسنجی مدل.

## ابزارهای خارجی و نسخه‌ها

مسیر معمول تبدیل به این ابزارها نیاز دارد:

1. **CodeWalker**: بازکردن RPF/YFT و صادرکردن XML و تکسچرهای خودرو.
2. **Blender 4.0+ و Sollumz**: واردکردن XML صادرشده از CodeWalker و انتقال مدل/تکسچرها به فرمت واسط. نکته: طبق FAQ رسمی Sollumz، افزونه فایل XML صادرشده از CodeWalker را وارد می‌کند؛ YFT باینری خام را مستقیماً وارد نکنید.
3. **Blender 3.1 تا 3.6 و افزونه DGIorio NFSMW exporter**: آماده‌سازی و خروجی مدل برای NFS MW 2012. برای مسیر قدیمی NFSMW12VMT از Blender 3.4 استفاده می‌شود.
4. **Noesis و پلاگین‌های NFS MW 2012 / Bundle Packer-Unpacker**: بازکردن خودروی مرجع و بسته‌بندی منابع بازی.
5. **NVIDIA Texture Tools** در مسیرهای خاص برای پردازش تکسچر.

ممکن است به دو نصب جداگانه Blender نیاز باشد: Blender 4+ برای Sollumz و Blender 3.6 یا 3.4 برای افزونه خروجی MW12. نسخه این افزونه‌ها با هم یکی نیست.

## ساخت EXE از GitHub Actions

1. کل محتوای پروژه را در ریپوی GitHub قرار بده.
2. به زبانه Actions برو.
3. Workflow با نام **Build Windows EXE** را اجرا کن یا روی `main`/`master` پوش کن.
4. فایل `NFS-GTA-V-Mod-Converter.exe` را از Artifacts دانلود کن.

Workflow فقط روی Windows اجرا می‌شود و ابتدا تست‌ها را اجرا می‌کند.

## گردش‌کار تبدیل پیشنهادی

1. پوشه بازی را انتخاب کن؛ برنامه فهرست فایل‌های `VEHICLES/*.BNDL` را می‌خواند.
2. مود GTA V و خودروی مقصد را انتخاب کن و «ساخت فضای تبدیل» را بزن.
3. اگر مود داخل RPF است، در CodeWalker آن را باز کن؛ YFT و YTD مرتبط را به XML و تکسچرها صادر کن و داخل `02_CodeWalker_XML_Export` قرار بده.
4. XML را در Sollumz/Blender 4+ وارد کن. مدل را با درنظرگرفتن مقیاس، جهت، UV، چرخ‌ها، شیشه، چراغ و اجزای بدنه به FBX/OBJ و تکسچرهای جداگانه منتقل کن.
5. خودروی مرجع NFS را در Noesis باز/استخراج کن و ساختار آن را بررسی کن. مدل GTA باید برای ساختار NFS تطبیق داده شود؛ صرفاً جایگزین‌کردن فایل‌ها کافی نیست.
6. در Blender 3.6 با افزونه DGIorio خروجی NFS را بساز و آن را با Bundle Packer/Unpacker به BNDL بسته‌بندی کن. در مسیر جایگزین NFSMW12VMT، قواعد Mesh/Material/Texture ذکرشده در README ابزار را رعایت کن.
7. پوشه OBJ/MTL/DDS را در برنامه اعتبارسنجی کن. سپس BNDL خروجی را انتخاب و نصب کن.
8. برای برگشت به حالت اصلی، مود GTA V مربوط را در زبانه مدیریت مود انتخاب و حذف کن.

## نکات فنی مهم

- یک Mesh با چند Material برای مسیر قدیمی NFSMW12VMT مجاز نیست.
- سقف ۶۰٬۰۰۰ رأس در README ابزار قدیمی به‌عنوان محدودیت گزارش شده؛ در این برنامه به‌صورت خطای اعتبارسنجی دیده می‌شود.
- برنامه فقط وجود و ساختار فایل BNDL را کنترل مقدماتی می‌کند؛ صحت کامل منابع داخل BNDL یا اجرای موفق بازی را نمی‌تواند بدون اجرای خود بازی تضمین کند.
- هنگام نصب/حذف مود، بازی و لانچر را ببند.
- فایل اصلی BNDL فقط پس از ساخت بکاپ و تأیید مسیر جایگزین می‌شود.
